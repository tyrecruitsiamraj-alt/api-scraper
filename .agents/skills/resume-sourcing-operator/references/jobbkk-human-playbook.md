# วิธีค้น JobBKK ตามที่คนทำมือ (ยืนยันจากหน้าจริง 2026-09-10)

ห้ามเก็บชื่อ เบอร์ อีเมล LINE ที่อยู่ หรือเนื้อหา Resume จากคลิปสอนลงไฟล์นี้

## ลำดับที่ต้องทำเหมือนคน

1. Login ผู้ประกอบการ แล้วเข้า **Resume Search Talent** ที่ `/resume/lists` ไม่ใช้หน้า premium เก่าเป็นทางหลัก
2. อยู่แท็บ **Normal Search** กรอกเงื่อนไขที่มีในใบขอก่อน ค่อยคิดถึง **AI SEARCH**
3. กรอกตามลำดับหน้าเว็บ: ชิปตำแหน่ง → ชิป Keyword → ประเภทงาน/สาขาอาชีพ → จังหวัด
4. กรอกตัวกรองเพิ่มถ้าใบขอมีค่า: วุฒิ เพศ เงินเดือน อายุ รูปแบบงาน ประสบการณ์
5. กด **ค้นหาผู้สมัครงาน** แล้วรอจนผลเปลี่ยน
6. ถ้าผลเป็น 0: ผ่อน Normal ทีละชั้น ห้ามกระโดดไป AI ทันที
7. **AI SEARCH ใช้เติมจำนวนเท่านั้น** เมื่อ Normal ได้ไม่ถึงเป้า
8. เปิด `/resumes/preview_new/{id}` รอจนหน้า Resume วาดครบ แล้วค่อยอ่าน

## กติกาเขียนโค้ด

- ค่าที่ใบขอไม่มี ห้ามเดาแล้วไปติ๊กให้
- ตำแหน่ง/Keyword ต้องเป็นชิปที่ JobBKK รับ
- ข้อมูลบนหน้า Resume ไม่ถือว่าถูกปิด ถ้าคนเห็นได้ ระบบต้องอ่านได้
