# วิธีคิดของผู้กำกับศิลป์งานสรรหา

## หน้าที่ของภาพ

ทำให้คนหยุดดู รู้ตำแหน่ง และเห็นข้อมูลสำคัญตามลำดับ ภาพไม่ต้องเล่าทุกอย่างแทน Caption

## คิดภาพก่อนเลือก Template

ตอบหกข้อ:

1. **Subject:** ใครหรืออะไรเป็นพระเอก
2. **Context:** ฉากใดช่วยยืนยันอาชีพโดยไม่ทำให้เข้าใจผิด
3. **Moment:** กำลังทำอะไร ไม่ยืนโพสแบบภาพสต็อกโดยไม่มีเหตุผล
4. **Mood:** อยากให้รู้สึกอย่างไร เช่น น่าเชื่อถือ คล่องตัว อบอุ่น หรือแม่นยำ
5. **Hierarchy:** ตาเห็นอะไรเป็นอันดับ 1, 2, 3
6. **Proof:** ข้อมูลใดบนภาพช่วยให้ตัดสินใจจริง

## ลำดับสายตาบังคับ

1. ตำแหน่งงาน
2. ภาพคนหรือบริบทที่ตรงอาชีพ
3. จุดขายจริงหนึ่งจุด เช่น พื้นที่ รายได้ หรือเวลางาน
4. CTA/ช่องทางสมัคร
5. รายละเอียดรอง

ถ้าทุกอย่างใหญ่เท่ากัน แปลว่ายังไม่มีลำดับสายตา

## แนวภาพตามธรรมชาติของงาน

- **งานบริการ/ประชาสัมพันธ์:** human editorial, สีอบอุ่น, สีหน้าและการสบตาเด่น, ฉากสะอาด
- **งานขับรถ/ภาคสนาม:** documentary action, เห็นอุปกรณ์หรือยานพาหนะพอให้รู้บริบท, ท่าทางมั่นใจและปลอดภัย
- **งานช่าง/เทคนิค/IT:** functional, grid ชัด, contrast สูง, เห็นเครื่องมือหรือสภาพแวดล้อมจริง
- **งานปฏิบัติการ/จำนวนมาก:** bold local, อ่านเร็ว, สีเด่น, ข้อมูลไม่ซับซ้อน
- **งานรักษาความปลอดภัย:** structured, disciplined, trustworthy; หลีกเลี่ยงท่าทางก้าวร้าว

ให้ใช้เป็นจุดเริ่ม ไม่ใช่ Template ตายตัว ปรับตาม Persona และสถานที่จริง

## Composition

- เว้นพื้นที่ปลอดภัยให้ข้อความตั้งแต่ตอนสร้างภาพ
- ใช้คน 1 คนเป็นค่าเริ่มต้น เพิ่มคนเมื่อแนวคิดต้องการ “ทีม” จริง ๆ
- ครอปรูปให้เห็นอาชีพ ไม่ตัดอุปกรณ์สำคัญ
- จำกัดกลุ่มข้อความหลัก 3–5 กลุ่ม
- ตรวจที่ขนาดมือถือก่อนอนุมัติ

## การสร้างภาพด้วย AI

สั่งเฉพาะคน ฉาก แสง มุมกล้อง เสื้อผ้า อุปกรณ์ ท่าทาง และพื้นที่ว่าง ห้ามให้โมเดลวาดข้อความ โลโก้ ป้าย หรือ QR Code

ตัวอย่างโครง Prompt:

`Thai [role], performing [realistic action], wearing [accurate attire], [work context], [camera and light], authentic confident expression, composition leaves clean negative space on [side], photorealistic, no text, no logo, no signage, no watermark`

## Visual Brief ที่ต้องส่ง

- Concept name
- Subject/action
- Scene and props
- Composition/negative space
- Typography hierarchy
- Color/mood
- Image prompt
- Do/Don't
- เหตุผลที่เหมาะกับ Persona และ Angle
