# Quality Gate และ KPI

## Quality Gate ก่อนอนุมัติ

ให้คะแนน Pass/Fail พร้อมหลักฐานต้นทาง:

1. ตำแหน่งและจำนวนตรงใบขอ
2. พื้นที่และเวลาทำงานตรงใบขอ
3. เงินเดือนและสวัสดิการไม่ถูกแต่งเพิ่ม
4. คุณสมบัติและใบอนุญาตถูกต้อง
5. ช่องทางติดต่อถูกต้อง
6. ภาษาชัดและเหมาะกับกลุ่มเป้าหมาย
7. รูปไม่ทำให้เข้าใจตำแหน่งผิด
8. ไม่มีข้อมูลส่วนบุคคลหรือถ้อยคำเสี่ยงโดยไม่จำเป็น

ถ้ามี Fail ในข้อ 1–5 ห้ามเสนออนุมัติ ให้แก้ก่อน

## ลำดับคุณค่าของผลลัพธ์

Qualified Candidate > ผู้สนใจที่ติดต่อได้และไม่ซ้ำ > คอมเมนต์ที่มีเจตนาสมัคร > แชร์ > Reaction

ห้ามใช้ยอด Reaction เป็นตัวแทนความสำเร็จของการสรรหา

## KPI ของ Skill

| KPI | เป้าหมาย POC |
|---|---:|
| งานสำเร็จโดยไม่ต้องให้คนตาม | ≥ 95% |
| ประกาศผ่านการตรวจรอบแรก | ≥ 80% |
| ข้อเท็จจริงสำคัญผิด | 0 |
| โพสต์ซ้ำจากระบบ | 0 |
| ลดเวลาตั้งแต่รับงานถึงพร้อมเผยแพร่ | ≥ 70% |
| งานที่มีเหตุผลอนุมัติ/ปฏิเสธครบ | 100% |
| งานติดปัญหาแต่ไม่แจ้งเตือน | 0 |

## เกณฑ์เรียนรู้

- แยก `human_feedback` ออกจากผล `measured`
- เปรียบเทียบบริบท Job Family พื้นที่ กลุ่ม และช่วงเวลาใกล้เคียงกัน
- รอเวลาขั้นต่ำและปรับคะแนนตามจำนวนกลุ่ม
- อย่าเลื่อน Pattern เป็นมาตรฐานจากผลครั้งเดียว
- ลดน้ำหนัก Pattern ที่เก่าหรือบริบทเปลี่ยนอย่างมีนัยสำคัญ
