# นโยบายการตัดสินใจ

## เลือกเส้นทางงาน

| สถานการณ์ | การตัดสินใจหลัก | เหตุผล |
|---|---|---|
| มี Candidate Spec ชัด และต้องการคนน้อย | ค้นหาผู้สมัครก่อน | เร็วกว่าและคัดคนได้ตรงกว่า |
| คลังผู้สมัครไม่พอหรือไม่มีคนตรง | สร้างประกาศ | เปิดรับ Demand ใหม่จากตลาด |
| ต้องการหลายคนหรือกำหนดเริ่มงานเร่งด่วน | ทำสองทางพร้อมกัน | ลดความเสี่ยงจากช่องทางเดียว |
| ข้อมูลตำแหน่ง รายได้ หรือพื้นที่ขัดกัน | หยุดและถามคน | เสี่ยงประกาศผิดและเสียความน่าเชื่อถือ |
| ไม่มีบัญชีหรือกลุ่มที่พร้อม | เตรียมบัญชีก่อน | ป้องกันงานไปค้างหลังอนุมัติ |

## ระดับอำนาจ

ระบบทำได้เอง: ตรวจข้อมูล วิเคราะห์ Candidate Spec สร้างและแก้ร่าง ตรวจ Quality Gate แนะนำตัวเลือก ส่งคิวที่อนุมัติแล้ว ลองใหม่เมื่อผิดพลาดชั่วคราว และวัดผล

ต้องให้คนอนุมัติ: เผยแพร่จริงในช่วง POC, ใช้ข้อมูลที่ใบขอไม่ได้ระบุ, เปลี่ยนเงื่อนไขงาน/บัญชี/กลุ่ม และเลื่อน Pattern เป็นมาตรฐานเมื่อข้อมูลยังไม่พอ

ต้องหยุดและแจ้งคน: Facebook ขอ OTP หรือจำกัดบัญชี, ข้อมูลรับรองผิด, ข้อมูลต้นทางขัดกัน, ลองใหม่ครบแล้วยังล้มเหลว หรือเสี่ยงเผยแพร่ข้อมูลส่วนบุคคล

## เงื่อนไขหยุด

- หยุดค้นหา/โพสต์เมื่อได้ผู้สมัครผ่านเกณฑ์ครบเป้าหมาย หรือถึงโควตาที่ตกลง
- หยุดทดลองเมื่อความเสี่ยงบัญชีสูงขึ้นหรือข้อมูลยังไม่พอเปรียบเทียบอย่างยุติธรรม
- เมื่อแก้ครบ 3 รอบแล้วยังไม่ผ่านด้วยเหตุผลเดิม ให้ส่งคนตัดสินใจแทนการสร้างร่างไม่สิ้นสุด
