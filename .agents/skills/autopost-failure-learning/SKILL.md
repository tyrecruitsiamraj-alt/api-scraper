# ผู้ดูแลบทเรียนความผิดพลาด Autopost

เป้าหมายคือทุกความผิดพลาดต้องกลายเป็นกติกาป้องกันที่ตรวจได้ ไม่ใช่เพียง Log ที่อ่านแล้วหายไป

## ก่อนลบข้อมูลทดสอบ

1. ตรวจว่าไม่มี `post_logs` หรือ post link ที่ยืนยันว่าเผยแพร่จริง
2. บันทึก Lesson ลง `operational_failure_lessons` ก่อนเสมอ โดยเก็บเฉพาะหมวดสาเหตุ วิธีป้องกัน เวลา และรหัสงาน ห้ามเก็บรหัสผ่าน Token หรือข้อมูลผู้สมัคร
3. แยก `preflight` ออกจาก `post` เสมอ: Preflight ที่ล้มเหลวไม่ใช่โพสต์จริง
4. ลบได้เฉพาะ run/log ที่เจ้าของยืนยันว่าเป็นการทดสอบหรือ obsolete; ห้ามลบหลักฐานของโพสต์จริง

## กติกาป้องกันซ้ำ

- Session/Checkpoint: ต้องผ่าน Preflight ของบัญชีเดียวกันภายใน 24 ชั่วโมงก่อนโพสต์จริง
- Worker เก่าหรือไม่มี Build Contract: ไม่ให้รับงานของบัญชีที่ Pin แล้ว
- Timeout: หยุด retry อัตโนมัติ พักบัญชี และวิเคราะห์ก่อนลองใหม่
- สาเหตุไม่ทราบ: ห้าม retry แบบเดา; เก็บหลักฐานและแจ้งคนรับผิดชอบ
- Auto Daily: เปิดได้เมื่อผู้รับผิดชอบอนุมัติเท่านั้น ไม่ถือว่าการเปิด capability `post` คืออนุญาต Auto Daily

## หลังทุก Failure

รายงานเป็นภาษาไทย: สิ่งที่เกิดขึ้น, เป็นการทดสอบหรือไม่, บทเรียนที่บันทึก, กติกาที่ป้องกันแล้ว, และสิ่งที่ต้องให้คนอนุมัติถ้ามี
